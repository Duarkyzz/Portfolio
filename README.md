## 🚀 Sobre o projeto

O portfólio foi desenvolvido do zero utilizando **HTML, CSS e JavaScript**, com uma interface moderna, responsiva e focada em uma navegação simples.

O objetivo é reunir em um único lugar meus principais projetos, conhecimentos e formas de contato enquanto continuo evoluindo na área de desenvolvimento.

## ✨ Principais características

* 🌙 Interface dark com identidade visual em roxo
* 📱 Layout responsivo para desktop e dispositivos móveis
* ✨ Animações suaves durante a navegação
* 🪟 Cards com efeitos de transparência e interação
* 🧭 Menu mobile interativo
* ♿ Navegação acessível por teclado
* ⚡ Estrutura leve, sem frameworks ou dependências externas

As animações respeitam a configuração de **movimento reduzido** do dispositivo e, mesmo sem JavaScript, o conteúdo principal continua disponível.

## 📂 Projetos em destaque

### 📡 StatusWatch

Projeto desenvolvido em Python para monitoramento de sites e APIs.

O sistema verifica disponibilidade, código HTTP e tempo de resposta, além de armazenar o histórico das verificações.

**Tecnologias:** Python, PostgreSQL, Supabase, PySide6 e Requests.

### 🔍 CodePulse

Projeto em Python voltado para análise de repositórios e código, com a proposta de identificar informações sobre estrutura, documentação, dependências, qualidade e possíveis problemas dentro de um projeto.

O projeto está atualmente em desenvolvimento.

## 💻 Executando localmente

Não é necessário instalar nenhuma dependência ou iniciar um servidor.

Clone o repositório:

```bash
git clone https://github.com/Duarkyzz/Portfolio.git
```

Depois, basta abrir o arquivo:

```text
index.html
```

no navegador.
